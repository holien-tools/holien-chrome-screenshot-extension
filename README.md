# 整頁截圖（Chrome 擴充功能）

**繁體中文** | [English](README.en.md)

在工具列按一下，就能把**整個網頁**（包含需要往下捲動才看得到的部分）擷取成圖片，擷取**目前看到的視窗畫面**，或像 Windows 剪取工具一樣**框選畫面的一部分**擷取，預覽時可以**加上框線、箭頭、文字、編號和馬賽克**，再下載到電腦（PNG 或 JPEG）或複製使用。

## 安裝

1. 下載這個 repo（`git clone` 或在 GitHub 按 **Code → Download ZIP** 後解壓縮）。
2. 在 Chrome 打開 `chrome://extensions`，開啟右上角的 **開發人員模式**。
3. 按 **載入未封裝項目**，選擇 repo 裡的 **`extension`** 資料夾（不是 repo 根目錄）。
4. 建議把擴充功能釘選到工具列：點拼圖圖示 → 在「整頁截圖」旁按圖釘。

## 使用

1. 打開要擷取的網頁。
2. 按工具列上的圖示，選擇：
   - **擷取整頁**：擷取時圖示上會顯示進度（%），**請停留在這個分頁直到完成**。
   - **擷取視窗**：只擷取目前看到的畫面，不包含網址列和瀏覽器工具列，不會捲動。
   - **框選範圍**：畫面會暫停並變暗，用滑鼠拖曳框出要擷取的範圍，放開就完成；按 Esc 取消。
3. 完成後會開新分頁顯示預覽，可以先加上框線、箭頭、文字等標註，再按 **下載** 存到電腦（PNG 或 JPEG），或按 **複製** 直接貼到聊天軟體或文件裡。

### 標註

在預覽頁的圖片上可以直接加標註，工具列選好工具後在圖片上拖曳或點一下：

| 工具 | 用法 |
| --- | --- |
| **框線** | 拖曳框出範圍 |
| **箭頭** | 從起點拖曳到箭頭所指的位置 |
| **文字** | 點一下輸入文字，Enter 完成、Shift+Enter 換行、Esc 取消；點兩下已有的文字可以修改 |
| **編號** | 點一下放一個 ①②③，依放置順序自動編號，刪掉其中一個會自動重新編號 |
| **馬賽克** | 拖曳框出要打碼的範圍（帳號、Email、金額等） |

- **顏色**：紅、綠、藍、黃、橘、黑、白，或按 **自訂** 挑任何顏色。
- **大小**：小、中、大，同時決定線條粗細、文字大小、編號圓圈大小和馬賽克的格子大小（以螢幕上看到的大小為準，高解析度螢幕也一樣）。
- **移動和調整**：拖曳標註就能移動；點一下選取後，框線、馬賽克和箭頭會出現控制點，拖曳可以調整大小或改變箭頭的端點。
- **刪除**：點一下選取再按 Delete；按 **復原**（或 Ctrl+Z）拿掉最後加的一個；按 **全部清除** 清掉所有標註。拖曳到一半按 Esc 可以取消。

標註先顯示在預覽上，按 **下載** 或 **複製** 時才會**自動合併進圖片**；沒有標註的話，輸出的就是原始截圖。標註會跟截圖一起存在瀏覽器裡，關掉預覽頁再打開還在（截圖本身只保留最近 3 次）。

### 下載格式

工具列的 **格式** 可以選 **PNG**（預設，無損）或 **JPEG**（檔案小很多，適合貼到聊天軟體或 email），選 JPEG 時可以用滑桿調整品質（50% 到 100%，預設 90%）。選擇會記住，下次預覽也一樣。**複製** 固定用 PNG，因為剪貼簿只接受 PNG 圖片。

### 快捷鍵

| 功能 | 預設快捷鍵 |
| --- | --- |
| 擷取整頁 | Alt+Shift+F |
| 擷取視窗 | Alt+Shift+V |
| 框選範圍 | Alt+Shift+S |

Mac 上的 Alt 是 Option 鍵。如果按鍵已經被其他擴充功能使用，Chrome 不會自動指定，可以到 `chrome://extensions/shortcuts` 修改或自己設定。

### 設定

按工具列圖示選 **設定**（或在圖示上按右鍵 → **選項**），可以調整擷取整頁時最多擷取幾個畫面，預設 50 個，可以設定 1 到 200。數字越大，擷取越久、圖片也越多：在 4K 螢幕上，200 個畫面大約要 3 分鐘。有開啟 Chrome 同步的話，設定也會同步到其他電腦。


## 擷取整頁時怎麼處理捲動

Chrome 一次只能截取目前看得到的畫面，所以擴充功能會：

- 從頁面最上方開始，一次捲動一個畫面並截圖，最後把所有畫面依捲動位置接成一張圖。
- **固定（fixed）元素**：頁首和側邊欄只出現在第一個畫面（比視窗高的側邊欄會像在螢幕上一樣被切在視窗底部），固定在底部的元素（例如 cookie 提示列、浮動按鈕）只出現在最後一個畫面，不會在圖片裡重複出現。有些頁面（例如 Magento 後台）的工具列是捲動後才用 JavaScript 固定住的，所以每個畫面截圖前都會重新檢查一次。
- **黏性（sticky）元素**：擷取時暫時改回一般排版，只出現在它原本的位置，不會每個畫面都黏在上面。
- **平滑捲動**：擷取時暫時關閉，避免畫面在動畫途中被截到。
- **捲軸**：擷取時暫時隱藏，不會出現在圖片裡。
- **延遲載入的圖片**：每捲到一個畫面，會等畫面內的圖片載入完成（最多 1.5 秒）再截圖。
- **內層捲動的網頁**：有些網頁（像 Gmail、Notion 這類應用程式版面）是頁面裡的某個區塊在捲動，而不是整個視窗。這種情況會自動找出主要的捲動區塊，擷取它的完整內容。
- **捲動時會自動載入更多內容的網頁**（無限捲動，例如 Yahoo 首頁、社群網站動態牆）：會跟著新載入的內容繼續往下擷取，**擷取到設定的畫面數（預設 50 個）就停止**，預覽頁會提示。

擷取完成後，捲動位置和樣式都會還原成原本的樣子。

## 限制

- **擷取整頁有畫面數上限**：預設 50 個，可以在設定頁調整（1 到 200）。無限捲動的頁面（例如社群網站動態牆）會一直載入新內容，很長的一般頁面也一樣，擷取到上限就停止，預覽頁會提示。
- **圖片太高會分成多張**：單張圖片最高 16384 像素。頁面較長時（一般螢幕大約超過 20 個畫面，高解析度螢幕更少）會由上到下分成多張，預覽頁可以一次全部下載。
- **框選範圍只能框目前看得到的畫面**：要框其他部分，請先捲動到那裡，或改用擷取整頁。
- **只能擷取網頁內容**：瀏覽器工具列、其他視窗和桌面都擷取不到。
- **無法擷取的頁面**：`chrome://` 開頭的瀏覽器頁面、Chrome 線上應用程式商店，以及部分內建檢視器，Chrome 不允許擴充功能存取。
- **本機檔案**（`file://`）：需要在 `chrome://extensions` 的擴充功能詳細資料中開啟「允許存取檔案網址」。
- 只擷取垂直方向；如果頁面可以左右捲動，只會擷取目前看得到的寬度。
- 擷取速度受 Chrome 限制（每秒最多截圖 2 次），所以每個畫面大約需要 0.5 秒以上，擷取滿 50 個畫面至少要 30 秒。
- 只會保留最近 3 次的截圖，請在預覽頁及時下載。

## 權限

- `activeTab`：只有在你按下圖示或快捷鍵時，才能存取目前這個分頁並截圖。
- `scripting`：在頁面中執行捲動、調整樣式和顯示框選畫面的程式。
- `storage`：儲存你的設定（畫面數上限、下載格式）。

不需要「讀取所有網站資料」權限，也不會把任何資料傳到網路上，截圖只存在你的瀏覽器裡。

## 開發

```
extension/               ← 在 Chrome 載入這個資料夾
  manifest.json
  background.js          擷取流程：整頁（捲動、截圖、拼接、分割）、視窗（截圖）和框選（截圖、裁切）
  popup/                 按工具列圖示時出現的選單
  options/               設定頁
  content/capture-helper.js
                         注入頁面：找出捲動區塊、處理 fixed/sticky、捲動、還原
  content/area-select.js 注入頁面：顯示暫停的畫面讓使用者框選
  lib/settings.js        使用者設定（擷取畫面數上限、下載格式與品質）
  lib/store.js           用 IndexedDB 把截圖交給預覽頁，並保存標註
  result/                預覽、標註、下載與複製頁
  result/annotate.js     在圖上畫框線、箭頭、文字、編號、馬賽克，並在輸出時合併進圖片
  _locales/              英文、繁體中文介面文字
tests/
  e2e.mjs                端對端測試
  pages/                 測試用網頁
```

### 測試

測試會用 Playwright 啟動 Chromium、載入擴充功能、擷取 `tests/pages` 裡的測試網頁（整頁、視窗和框選），並逐列檢查圖片顏色是否正確，也會在預覽頁加上各種標註、移動和調整它們，檢查複製和下載出來的圖片，以及重開預覽頁後標註還在（分別在 1 倍與 2 倍螢幕縮放下執行）。

```sh
npm install
npx playwright install chromium   # 第一次執行時需要
npm test
HEADED=1 npm test                 # 開視窗看它執行
TEST=boxes npm test               # 只跑名稱包含 boxes 的測試
```

擷取到的圖片會存在 `test-output/`，可以直接打開檢查。
